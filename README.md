# Typewriter-Vin

An Obsidian theme that makes notes look typed on aged, premium book paper.

- **Font:** Special Elite, a worn typewriter face. It's embedded in `theme.css`, so it works offline.
- **Paper:** faded yellow book paper with a fine grain, small scattered pores, uneven age-toning and a slight vignette at the edges.
- **Code blocks:** a plain tinted panel with no borders or lines.
- **Ink:** black-brown ribbon ink with a faint bleed. Links, tags and checkboxes use the red half of the ribbon.
- **Typewriter habits:** bold is shown as a double strike, italics as an underline, and section breaks (`---`) as `*   *   *`.
- **Dark mode:** the same book read by lamplight, with dark sepia paper and cream ink.

## Install

1. Copy this `Typewriter-Vin` folder into `<your vault>/.obsidian/themes/`.
2. In Obsidian, go to **Settings → Appearance → Themes** and pick **Typewriter-Vin**.
